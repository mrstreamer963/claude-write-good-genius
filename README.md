# SP / Эсперы — POC (walking skeleton)

Нуарный симулятор подземной базы (коты-мусорщики). Дизайн: [concept.md](concept.md).

Пайплайн `bevy_ecs → WASM → WebWorker → PixiJS` собран и работает (шаг 0 плана POC, §11
concept.md). Сейчас идёт **шаг 2**: коты как сущности с задачами. Готово — постройка и снос
тайлов игроком, движение по BFS-пути, приказы, четыре вида работы на одном пуле свободных котов
(стройка · снос · подвоз материала · уборка), экономика материала (тайл стоит лом, снос его
возвращает, склад коты наполняют сами) и навыки: чем больше кот строит, тем быстрее работает.
На очереди Needs.

## Архитектура

```
        Главный поток                       WebWorker
   ┌──────────────────────┐          ┌──────────────────────────┐
   │ PixiJS               │  ◄─snap── │ Rust + bevy_ecs (WASM)   │
   │ рендер тайлов/юнитов  │          │ World + Schedule (тик)   │
   │ UI, ввод, скорость   │  ─speed─► │ YAML-рулсет (serde_yaml) │
   └──────────────────────┘          └──────────────────────────┘
```

- **Симуляция** — `src/` (bevy_ecs), авторитетна и детерминирована.
- **Контент** — `assets/rulesets/core.yaml` (стиль OpenXcom Extended).
- **Рендер/UI** — `web/src/main.js` (PixiJS), «тонкий» вид.
- **Тик/связь** — `web/src/worker.js`: фиксированный `dt`, скорость = тиков/сек.

## Требования

Rust + `wasm-pack`, Node (для Vite). Цель `wasm32-unknown-unknown`:

```bash
rustup target add wasm32-unknown-unknown
```

## Сборка и запуск

Быстрый старт через `make`:

```bash
make setup   # один раз: wasm-таргет + веб-зависимости
make dev     # собрать WASM и поднять dev-сервер (http://localhost:5173)
```

`make help` — список целей (`wasm`, `build`, `run`, `clean`). После правок в `src/` или
`assets/*.yaml` достаточно перезапустить `make dev` (пересоберёт WASM; Vite подхватит фронт).

> ⚠️ После пересборки WASM **под уже запущенным** dev-сервером Vite может отдавать старую
> wasm-обёртку из кэша. Перезапусти `make dev` (или почисти `web/node_modules/.vite`).

<details><summary>То же самое вручную, без make</summary>

```bash
wasm-pack build --target web --out-dir web/src/wasm   # ядро -> WASM
npm --prefix web install                               # веб-зависимости
npm --prefix web run dev                               # dev-сервер :5173
```
</details>

## Что должно быть видно

Тёмная тайловая сетка, три зоны (Склад / Лаборатория / Гараж), три кота (`excellent`, `sp2`,
`sp3`) и три кучи лома на складе. В шапке — счётчик лома и `tick`; кнопки ⏸/×1/×5/×10 меняют
темп, на паузе всё замирает (размечать при этом можно).

Что попробовать:

- **Курсор** — клик по коту выбирает его, клик по полу отправляет туда. У выбранного кота
  справа открывается панель: уровень «Стройки», опыт до следующего уровня, объём лап и перки.
- **Навык растёт от работы** — +1 очко опыта за каждый тик за делом, и каждый уровень добавляет
  скорости (новичок кладёт тайл за 12 тиков, мастер за 8). Снос растит тот же навык, что стройка:
  домен работы один. За переноску лома навык не растёт — это перк, а не мастерство.
- **Постройка** — выбрать тайл в палитре и протянуть рамку (`Esc` отменяет начатую). Площадка
  сперва бледная: коты везут на неё лом, полоска внизу клетки показывает подвоз, и только
  потом начинается работа. Цена тайла — цифра на кнопке палитры.
- **Стереть** — рамкой же. По размеченному снимает разметку, по построенному планирует снос:
  коты разбирают область от глубины к берегу и возвращают лом на пол.
- **Лом с пола коты свозят на склад сами** — склад это любая клетка тайла «Склад» (у неё есть
  ёмкость). Кнопка «Убирать сам» выключает автоуборку, «На склад» размечает рамкой конкретные
  кучи. Кота выбирать не нужно: как и чертёж, задачу возьмёт любой свободный.
- Снести пол под котом можно — он выйдет сам; если выйти некуда, вокруг него загорится
  оранжевое кольцо (`stuck`, состояние обратимое).

## Известные упрощения (каркас)

- Рендер снапит позиции по тайлам; интерполяция между тиками — TODO (§8b).
- Снапшот — полное состояние каждый кадр; диффы/`SharedArrayBuffer` — позже (§8a).
- Материал один — «лом»; типы предметов придут на шаге 3 (§12.15).
- Навык пока один («Стройка»), и на одном домене бригада рано или поздно упрётся в потолок.
  Врождённые параметры кота, которые различали бы котов навсегда, отложены до найма (§12.19);
  обучение навыку, работы по которому ещё нет, — до науки (§12.18).
- Склад типо-агностичен и без приоритетов: «ящик у лаборатории», который коты пополняют, —
  отложенная идея, см. конец §12.16.
