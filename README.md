# SP / Эсперы — POC (walking skeleton)

Нуарный симулятор подземной базы (коты-мусорщики). Дизайн: [concept.md](concept.md).

Пайплайн `bevy_ecs → WASM → WebWorker → PixiJS` собран и работает (шаг 0 плана POC, §11
concept.md). **Шаги 2 и 3 закрыты**: коты как сущности с задачами, предметы с типами. Готово —
постройка и снос тайлов игроком, движение по BFS-пути, приказы, четыре вида работы на одном пуле
свободных котов (стройка · снос · подвоз материала · уборка), экономика материала (тайл стоит
набор предметов, снос возвращает его целиком, склад коты наполняют сами), навыки (чем больше кот
строит, тем быстрее работает) и усталость: уставший кот сам уходит на лежанку. Дальше — шаг 4:
отряд, миссия и авторасчёт исхода.

## Архитектура

```
        Главный поток                       WebWorker
   ┌──────────────────────┐          ┌──────────────────────────┐
   │ PixiJS               │  ◄─snap── │ Rust + bevy_ecs (WASM)   │
   │ рендер тайлов/юнитов  │          │ World + Schedule (тик)   │
   │ UI, ввод, скорость   │  ─speed─► │ YAML-рулсет (serde_yaml) │
   └──────────────────────┘          └──────────────────────────┘
```

- **Симуляция** — `src/` (bevy_ecs), авторитетна и детерминирована.
- **Контент** — `assets/rulesets/core.yaml` (стиль OpenXcom Extended).
- **Рендер/UI** — `web/src/main.js` (PixiJS), «тонкий» вид.
- **Тик/связь** — `web/src/worker.js`: фиксированный `dt`, скорость = тиков/сек.

## Требования

Rust + `wasm-pack`, Node (для Vite). Цель `wasm32-unknown-unknown`:

```bash
rustup target add wasm32-unknown-unknown
```

## Сборка и запуск

Быстрый старт через `make`:

```bash
make setup   # один раз: wasm-таргет + веб-зависимости
make dev     # собрать WASM и поднять dev-сервер (http://localhost:5173)
```

`make help` — список целей (`wasm`, `build`, `run`, `clean`). После правок в `src/` или
`assets/*.yaml` достаточно перезапустить `make dev` (пересоберёт WASM; Vite подхватит фронт).

> ⚠️ После пересборки WASM **под уже запущенным** dev-сервером Vite может отдавать старую
> wasm-обёртку из кэша. Перезапусти `make dev` (или почисти `web/node_modules/.vite`).

<details><summary>То же самое вручную, без make</summary>

```bash
wasm-pack build --target web --out-dir web/src/wasm   # ядро -> WASM
npm --prefix web install                               # веб-зависимости
npm --prefix web run dev                               # dev-сервер :5173
```
</details>

## Что должно быть видно

Тёмная тайловая сетка, три зоны (Склад / Лаборатория / Гараж — он же шлюз для вылазок) с зоной
отдыха в углу гаража, три
кота (`excellent`, `sp2`, `sp3`) и запас на складе: лом и детали. В шапке — счётчики по типам и
`tick`; кнопки ⏸/×1/×5/×10 меняют темп, на паузе всё замирает (размечать при этом можно).

Что попробовать:

- **Курсор** — клик по коту выбирает его, клик по полу отправляет туда. У выбранного кота
  справа открывается панель: уровень «Стройки», опыт до следующего уровня, объём лап и перки.
- **Навык растёт от работы** — +1 очко опыта за каждый тик за делом, и каждый уровень добавляет
  скорости (новичок кладёт тайл за 12 тиков, мастер за 8). Снос растит тот же навык, что стройка:
  домен работы один. За переноску лома навык не растёт — это перк, а не мастерство.
- **Коты устают.** Бодрость тратится за каждый тик бодрствования; уставший кот бросает очередь
  работ и сам уходит на «Лежанку» (зона отдыха в углу гаража). Лежанку занимает один кот:
  свободной не нашлось — работает до нуля и валится там, где стоял. Спящий пригашен и помечен
  «зззз», на голом полу восстанавливается вшестеро медленнее. Приказ игрока будит.
- **Постройка** — выбрать тайл в палитре и протянуть рамку (`Esc` отменяет начатую). Площадка
  сперва бледная: коты везут на неё материал, полоска внизу клетки показывает подвоз, и только
  потом начинается работа. Цена тайла — фишки на кнопке палитры: по цветной на каждый предмет.
- **Предметов два, и деталь взять негде.** Пол обходится ломом, но всё особенное (склад,
  лаборатория, гараж, лежанка) требует ещё и деталь, а производства в POC нет — единственный её
  источник — разбор стартовой базы. Чтобы построить лабораторию, придётся решить, что снести.
  За ходку кот везёт один тип: площадку с двумя предметами в цене снабжают в несколько заходов.
- **Стереть** — рамкой же. По размеченному снимает разметку, по построенному планирует снос:
  коты разбирают область от глубины к берегу и возвращают лом на пол.
- **Лом с пола коты свозят на склад сами** — склад это любая клетка тайла «Склад» (у неё есть
  ёмкость). Кнопка «Убирать сам» выключает автоуборку, «На склад» размечает рамкой конкретные
  кучи. Кота выбирать не нужно: как и чертёж, задачу возьмёт любой свободный.
- **Вылазка** — выберите котов (клик, `Shift`+клик — добавить в отряд) и жмите кнопку в разделе
  «Вылазки». Отряд игрок набирает **поимённо**: это единственная работа, где исполнителя не
  выбирает симуляция, потому что от состава зависит исход. Кнопка живая, только когда выделено
  ровно столько котов, сколько уходит. Коты сходятся к шлюзу (тайл «Гараж»), уходят полным
  составом и исчезают с карты; вернутся туда же и вывалят добычу кучей — дальше её разнесёт
  обычная уборка. Пока отряд на базе, его можно отозвать; ушедшего — уже нет.
- **Исход виден заранее.** В панели вылазки — «сила / сложность» и что из этого выйдет. Сила
  отряда это по коту единица плюс его уровень «Вылазки»; хватило — вся добыча, не хватило — её
  доля, вдвое меньше нужного — провал (красная полоса): вернутся ни с чем и без сил, свалятся
  спать прямо у шлюза. Броска кубика нет — тот же отряд на той же вылазке даст тот же результат.
- **Навык «Вылазка» растёт от вылазок** — очко за каждый тик в поле, и провал учит наравне с
  успехом. «Свалка» по силам стартовой тройке, «Разбор ангара» сперва отдаст половину добычи,
  а «Логово рейдеров» на старте гарантированно провалится: туда ходят, когда подрастут.
- **Вылазка — единственный доход базы.** Пока её не было, деталь бралась только из разбора
  стартового наследства: построил лабораторию — снёс гараж. Цена вылазки — котовремя: база
  остаётся без рук, пока отряд в поле, и он возвращается уставшим.
- **Известность (★ в шапке) открывает всё остальное.** Успех приносит её той же долей, что и
  добычу; провал не приносит ничего, но и не отнимает. «Разбор ангара» ждёт известности 20,
  «Логово» — 60: закрытые вылазки видны, чтобы было к чему идти. Известность не тратится.
- **Найм** — раздел «Найм» в тулбаре. Кандидат откликается на известность, а платят за него
  предметами **со склада**: то, что валяется на полу, ещё не сосчитано. Каждый приходит один раз
  и уже умеющим — «Гвоздь» это готовый ходок, «Кирпич» строитель. Отсюда и дилемма: детали на
  лабораторию или на новые лапы.
- Снести пол под котом можно — он выйдет сам; если выйти некуда, вокруг него загорится
  оранжевое кольцо (`stuck`, состояние обратимое). Снести гараж, пока отряд в поле, тоже можно:
  коты вернутся в яму и выберутся из неё сами, а добыча съедет на соседний пол.

## Известные упрощения (каркас)

- Рендер снапит позиции по тайлам; интерполяция между тиками — TODO (§8b).
- Снапшот — полное состояние каждый кадр; диффы/`SharedArrayBuffer` — позже (§8a).
- Предметов два, и оба — строительный материал; еда, снаряжение и образцы придут с миссиями
  и наукой. Склад типо-агностичен: ёмкость считает штуки, сортировки по типам нет (§12.21).
- Исход вылазки без разброса: тот же отряд на той же вылазке всегда даёт то же самое. Это
  сознательный выбор (§12.23) — на POC кубик спрятал бы связь «кого послал → что получил».
  Seeded-разброс поверх формулы отложен до 4c.
- Известность одна на всех: фракций, у которых репутация росла бы по-разному, ещё нет (§4.4,
  §12.7). Снаряжение и AutoEquip тоже вынесены дальше (§12.21). Миссия одна за раз.
- Кандидаты на найм — фиксированный список из рулсета, а не обновляющийся пул: ротация требует
  либо рандома против §11, либо расписания, которое всё равно писать в рулсет (§12.24).
- Провал не отнимает котов: он стоит бодрости и добычи. Потери и травмы — часть §12.5, которая
  ждёт 4c; §12.10 держит линию «состояния обратимы».
- Пока отряд в поле, коты не устают и вообще ничего не делают: вылазка — авторасчёт, а не
  вторая симуляция (§12.22). Плата снимается разом на возвращении.
- Потребность пока одна — усталость; голод ждёт типов предметов (§12.20).
- Навыков два («Стройка» и «Вылазка»), и на каждом домене бригада рано или поздно упрётся
  в потолок. Врождённые параметры кота, которые различали бы котов навсегда, отложены до найма
  (§12.19); обучение навыку, работы по которому ещё нет, — до науки (§12.18).
- Склад типо-агностичен и без приоритетов: «ящик у лаборатории», который коты пополняют, —
  отложенная идея, см. конец §12.16.
