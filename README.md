# SP / Эсперы — POC (walking skeleton)

Нуарный симулятор подземной базы (коты-мусорщики). Дизайн: [concept.md](concept.md).

Пайплайн `bevy_ecs → WASM → WebWorker → PixiJS` собран и работает (шаг 0 плана POC, §11
concept.md). **Шаги 2–8 закрыты, план POC пройден целиком**: коты как сущности с задачами, предметы с типами, вылазки с
исходом и наука. Готово — постройка и снос тайлов игроком, движение по BFS-пути, приказы, работа
на одном пуле свободных котов (стройка · снос · подвоз материала · уборка · наука), экономика
материала (тайл стоит набор предметов, снос возвращает его целиком, склад коты наполняют сами),
навыки трёх доменов и усталость, вылазки с детерминированным исходом, известность и найм,
исследование образцов: парта учит «Науке», лаборатория превращает образцы в технологии,
технологии открывают палитру, а записка отсчитывает даты, к которым база должна успеть. Последними
закрыты три долга: снаряжение (комбинезон с вылазки коты надевают сами со склада и он прибавляет
отряду силы там, где навык упёрся в потолок), производство — мастерская делает детали из лома и
комбинезоны из деталей, и у базы впервые появился источник, не зависящий от добычи, — и голод:
паёк коты добирают сами, а пустой желудок жжёт бодрость вдвое (шаг 9, §12.36). Дальше плана
пошёл шаг 10a: у провала вылазки появилась цена — коты **ранятся** (не гибнут: смерти в игре
нет), выбывают из работы и лечатся в лазарете, а свободный кот приходит к раненому медиком
(§12.5, §12.37).

## Архитектура

```
        Главный поток                       WebWorker
   ┌──────────────────────┐          ┌──────────────────────────┐
   │ PixiJS               │  ◄─snap── │ Rust + bevy_ecs (WASM)   │
   │ рендер тайлов/юнитов  │          │ World + Schedule (тик)   │
   │ UI, ввод, скорость   │  ─speed─► │ YAML-рулсет (serde_yaml) │
   └──────────────────────┘          └──────────────────────────┘
```

- **Симуляция** — `src/` (bevy_ecs), авторитетна и детерминирована.
- **Контент** — `assets/rulesets/core.yaml` (стиль OpenXcom Extended).
- **Рендер/UI** — `web/src/main.js` (PixiJS), «тонкий» вид.
- **Тик/связь** — `web/src/worker.js`: фиксированный `dt`, скорость = тиков/сек.

## Требования

Rust + `wasm-pack`, Node (для Vite). Цель `wasm32-unknown-unknown`:

```bash
rustup target add wasm32-unknown-unknown
```

## Сборка и запуск

Быстрый старт через `make`:

```bash
make setup   # один раз: wasm-таргет + веб-зависимости
make dev     # собрать WASM и поднять dev-сервер (http://localhost:5173)
```

`make help` — список целей (`wasm`, `build`, `run`, `clean`). После правок в `src/` или
`assets/*.yaml` достаточно перезапустить `make dev` (пересоберёт WASM; Vite подхватит фронт).

> ⚠️ После пересборки WASM **под уже запущенным** dev-сервером Vite может отдавать старую
> wasm-обёртку из кэша. Перезапусти `make dev` (или почисти `web/node_modules/.vite`).

<details><summary>То же самое вручную, без make</summary>

```bash
wasm-pack build --target web --out-dir web/src/wasm   # ядро -> WASM
npm --prefix web install                               # веб-зависимости
npm --prefix web run dev                               # dev-сервер :5173
```
</details>

## Что должно быть видно

Тёмная тайловая сетка, три зоны (Склад / Лаборатория / Гараж — он же шлюз для вылазок) с зоной
отдыха в углу гаража, три
кота (`excellent`, `sp2`, `sp3`) и запас на складе: лом и детали. В шапке — счётчики по типам и
`tick`; кнопки ⏸/×1/×5/×10 меняют темп, на паузе всё замирает (размечать при этом можно).

Что попробовать:

- **Тулбар — по разделам:** раскрыт ровно один (Постройка · Лом · Вылазки · Наука · Производство ·
  Обучение · Найм), остальные свёрнуты в заголовок. Механик стало больше, чем помещается в экран, а
  листать скроллом палитру, которой пользуешься каждые пять секунд, хуже, чем нажать заголовок.
  Справа — колонка «читать»: выбранный кот, вылазка, тема, заказ и записка складываются потоком.
  Кнопка «?» в шапке убирает подсказку по управлению, когда та мешает смотреть на базу.
- **Время — на клавишах:** пробел ставит паузу и снимает её, возвращая тот же темп (потерять ×10 из-за секундной остановки обидно), `1` / `2` / `3` — ×1, ×5, ×10. Клавиша узнаётся по
  физической кнопке, так что раскладка не важна.

- **Курсор** — клик по коту выбирает его, клик по полу отправляет туда. У выбранного кота
  справа открывается панель: уровень «Стройки», опыт до следующего уровня, объём лап и перки.
- **Навык растёт от работы** — +1 очко опыта за каждый тик за делом, и каждый уровень добавляет
  скорости (новичок кладёт тайл за 12 тиков, мастер за 8). Снос растит тот же навык, что стройка:
  домен работы один. За переноску лома навык не растёт — это перк, а не мастерство.
- **Врождённое даёт предел.** В карточке под именем — «Ум · Реакция · Выносливость»: это не
  вторая шкала мастерства, а потолок, докуда оно дойдёт. Ум ограничивает «Науку», Реакция —
  «Вылазку», Выносливость — «Стройку»; «Ремесло» и «Медицина» открыты всем до конца. Первый
  уровень не закрыт никогда, а полоска, вставшая раньше потолка, гаснет и подписывается
  «предел: Выносливость 4» — дальше этот кот не вырастет, сколько ни работай. Параметры не
  растут ни от чего: ровно поэтому коты остаются разными, когда бригада выработалась.
- **Коты устают.** Бодрость тратится за каждый тик бодрствования; уставший кот бросает очередь
  работ и сам уходит на «Лежанку» (зона отдыха в углу гаража). Лежанку занимает один кот:
  свободной не нашлось — работает до нуля и валится там, где стоял. Спящий пригашен и помечен
  «зззз», на голом полу восстанавливается вшестеро медленнее. Приказ игрока будит.
- **Постройка** — выбрать тайл в палитре и протянуть рамку (`Esc` отменяет начатую). Площадка
  сперва бледная: коты везут на неё материал, полоска внизу клетки показывает подвоз, и только
  потом начинается работа. Цена тайла — фишки на кнопке палитры: по цветной на каждый предмет.
- **Сперва деталь взять негде.** Пол обходится ломом, но всё особенное (склад, лаборатория,
  гараж, лежанка) требует ещё и деталь, а мастерская открывается только «Материаловедением»:
  до неё детали берутся из разбора стартовой базы и с вылазок. Чтобы построить лабораторию,
  придётся решить, что снести.
  За ходку кот везёт один тип: площадку с двумя предметами в цене снабжают в несколько заходов.
- **Стереть** — рамкой же. По размеченному снимает разметку, по построенному планирует снос:
  коты разбирают область от глубины к берегу и возвращают лом на пол.
- **Лом с пола коты свозят на склад сами** — склад это любая клетка тайла «Склад» (у неё есть
  ёмкость). Кнопка «Убирать сам» выключает автоуборку, «На склад» размечает рамкой конкретные
  кучи. Кота выбирать не нужно: как и чертёж, задачу возьмёт любой свободный.
- **Вылазка** — выберите котов (клик, `Shift`+клик — добавить в отряд) и жмите кнопку в разделе
  «Вылазки». Отряд игрок набирает **поимённо**: это единственная работа, где исполнителя не
  выбирает симуляция, потому что от состава зависит исход. Кнопка живая, только когда выделено
  ровно столько котов, сколько уходит. Коты сходятся к шлюзу (тайл «Гараж»), уходят полным
  составом и исчезают с карты; вернутся туда же и вывалят добычу кучей — дальше её разнесёт
  обычная уборка. Пока отряд на базе, его можно отозвать; ушедшего — уже нет. Ношу в лапах кот
  роняет кучей под ноги **сразу по заявке**: в поле лом не уезжает, а базе он нужен здесь и
  сейчас. Приказ «иди туда» груз при этом не роняет — кот сходит и донесёт (§12.38).
- **Исход виден заранее.** В панели вылазки — «сила / сложность» и что из этого выйдет. Сила
  отряда это по коту единица плюс его уровень «Вылазки»; хватило — вся добыча, не хватило — её
  доля, вдвое меньше нужного — провал (красная полоса): вернутся ни с чем и без сил, свалятся
  спать прямо у шлюза. Броска кубика нет — тот же отряд на той же вылазке даст тот же результат.
- **Навык «Вылазка» растёт от вылазок** — очко за каждый тик в поле, и провал учит наравне с
  успехом. «Свалка» по силам стартовой тройке, «Разбор ангара» сперва отдаст половину добычи,
  а «Логово рейдеров» на старте гарантированно провалится: туда ходят, когда подрастут.
- **Снаряжение коты надевают сами.** «Комбинезон» — обычный предмет: его привозят с вылазки, уборка
  свозит его на склад, а оттуда кот забирает его без всякой команды (шаблон один на всех, лежит
  в рулсете). В панели выбранного кота видно, что надето и сколько это даёт. Сила отряда растёт
  на ту же величину — это второй способ становиться сильнее, и в отличие от навыка он покупается
  добычей, а не временем. С пола снаряжение не берут: сперва его свезут на склад.
- **Производство** — раздел «Производство» в тулбаре, открывается «Материаловедением» вместе с
  самой «Мастерской». Клик заказывает одну штуку, `Shift` — пять; за верстак встанет ближайший
  свободный кот, допуска по навыку тут нет. Склад платит **за каждую штуку отдельно** и в тот
  момент, когда за неё берутся: пустой склад заказ не отменяет — тот просто ждёт материала, как
  площадка ждёт лом. Готовое падает под ноги мастеру, дальше его увозит обычная уборка.
  «Штамповка» делает деталь из лома (до неё детали брались только из разбора базы и с вылазок),
  «Пошив» — комбинезон, то есть силу отряда прямо из лома. Навык «Ремесло» растёт от работы и
  ускоряет её.
- **Коты едят сами.** «Паёк» — обычный предмет с сытостью: его привозят с вылазки, делает
  «Сухпаёк» в мастерской, и лежит он на складе или прямо на полу. Проголодавшийся свободный кот
  сходит к ближайшей куче и съест штуку на месте. Начатое дело голод не срывает, спящего не
  будит и никого не убивает — цену он берёт бодростью: **на пустой желудок она горит вдвое**,
  так что база без еды видна по тому, что вся бригада всё время спит. В панели кота — полоска
  сытости и подпись, когда пора обедать.
- **Провал сдирает снаряжение.** Раньше провальная вылазка стоила только бодрости, а она
  восстанавливается сама, — то есть ходить «на опыт» в заведомо непосильное логово было выгодно.
  Теперь оттуда возвращаются ободранными; успех снаряжение не изнашивает.
- **И ранит.** Здоровье — третья шкала кота, и единственная, которая сама не тикает: на базе
  ранить нечем, её роняет только вылазка. Урон считается **той же долей**, что и добыча: полный
  успех не царапает никого, полсилы стоят половины ран, провал — всех. Ниже порога кот выбывает:
  бросает начатое, ложится и в отряд не идёт, пока не заживёт. Заживает он и на голом полу, но
  медленно; койка «Лазарета» быстрее, а свободный кот, пришедший медиком, — ещё быстрее (навык
  «Медицина» растёт от самого лечения). Смерти в игре нет: платит база **котовременем**.
- **Вылазка — единственный доход базы.** Пока её не было, деталь бралась только из разбора
  стартового наследства: построил лабораторию — снёс гараж. Цена вылазки — котовремя: база
  остаётся без рук, пока отряд в поле, и он возвращается уставшим.
- **Известность (★ в шапке) открывает всё остальное.** Успех приносит её той же долей, что и
  добычу; провал не приносит ничего, но и не отнимает. «Разбор ангара» ждёт известности 20,
  «Логово» — 60: закрытые вылазки видны, чтобы было к чему идти. Известность не тратится.
- **Найм** — раздел «Найм» в тулбаре. Кандидат откликается на известность, а платят за него
  предметами **со склада**: то, что валяется на полу, ещё не сосчитано. Каждый приходит один раз
  и уже умеющим — «Гвоздь» это готовый ходок, «Кирпич» строитель. Отсюда и дилемма: детали на
  лабораторию или на новые лапы. Наведите на кандидата — во всплывающей подсказке его
  врождённые параметры: опыт база доберёт и сама, а предел даётся раз и навсегда, и смотреть
  надо на него.
- **Обучение** — выберите одного кота и жмите «Учить: Наука» в разделе «Обучение». Кот сядет за
  «Парту» (класс в лаборатории) и наберёт опыт до 2-го уровня — дальше только практика. Пока он
  учится, база остаётся без его лап: это и есть вся плата за специализацию. Без «Науки» кот не
  исследует **никак** — навык здесь допуск, а не скорость.
- **Наука** — раздел «Наука» в тулбаре. Тема оплачивается **образцами со склада** (их привозят
  с вылазок), а сядет за неё ближайший кот, которому хватает уровня: что изучать — решает игрок,
  кто изучает — симуляция. В панели справа видно прогресс и исполнителя; «Бросить» освобождает
  кота, но образцы не возвращает — их уже разобрали на опыты.
- **Технология открывает палитру.** «Материаловедение» открывает «Стеллаж» (втрое вместительнее
  склада), «Быт колонии» — «Гнездо» (вдвое быстрее лежанки). Закрытые тайлы видны и в подсказке
  говорят, какая тема их откроет. Две шкалы-ворота делят мир: известность открывает то, что
  снаружи (вылазки, кандидатов), технология — то, что внутри.
- **Записка** (слева внизу) знает даты. Заранее видны только дата и «скелет» события; ближе к
  сроку детали проступают — что именно спасёт и чем грозит. Первое событие приходит подарком
  к шлюзу, второе требует «Материаловедения»: успели — известность, не успели — бригада
  разгребает завал сама и валится спать. Прошедшее не стирается, а гаснет с исходом.
- **Коты не стоят друг на друге.** Сквозь идущего проходят — иначе коридор шириной в клетку встал
  бы намертво, — но встать вдвоём на одну клетку не остаются: занятый делом остаётся, свободный
  отходит на соседнюю. Отряд у шлюза — исключение: он там и собирается. На клетке с кучей стоять
  можно, предметы не мешают.
- **Отмена размеченной клетки возвращает завезённое.** Лом, который коты успели свезти на
  площадку, ложится кучей прямо на неё, а не пропадает; то, что носильщик несёт в лапах, он
  донесёт следующей ходкой.
- Снести пол под котом можно — он выйдет сам; если выйти некуда, вокруг него загорится
  оранжевое кольцо (`stuck`, состояние обратимое). Снести гараж, пока отряд в поле, тоже можно:
  коты вернутся в яму и выберутся из неё сами, а добыча съедет на соседний пол.

## Известные упрощения (каркас)

- Рендер снапит позиции по тайлам; интерполяция между тиками — TODO (§8b).
- Снапшот — полное состояние каждый кадр; диффы/`SharedArrayBuffer` — позже (§8a).
- Предметов пять: лом и деталь — строительный материал, образец — только для науки, комбинезон —
  только снаряжение, паёк — только еда. Склад типо-агностичен: ёмкость считает штуки, сортировки
  нет (§12.21).
- Снаряжение — один предмет и один шаблон на всех, слотов и характеристик нет: пока исход вылазки
  считается одним выражением, различать вещи нечем (§12.29).
- Производство — один заказ за раз и счётчик штук вместо очереди: очередь это приоритеты и
  вытеснение, а расставлять их некому, пока мастерская одна (§12.30). Рецептов три, все закрыты
  технологиями.
- Исход вылазки без разброса: тот же отряд на той же вылазке всегда даёт то же самое. Это
  сознательный выбор (§12.23) — на POC кубик спрятал бы связь «кого послал → что получил».
  Seeded-разброс поверх формулы отложен.
- Известность одна на всех: фракций, у которых репутация росла бы по-разному, ещё нет (§4.4,
  §12.7). Миссия одна за раз.
- Кандидаты на найм — фиксированный список из рулсета, а не обновляющийся пул: ротация требует
  либо рандома против §11, либо расписания, которое всё равно писать в рулсет (§12.24).
- Провал не отнимает котов **насовсем**: он стоит бодрости, добычи, снаряжения и здоровья.
  §12.10 держит линию «состояния обратимы» — ободранный отряд одевается заново, а раненый
  вылечивается. Плен, из которого кота вытаскивают отдельной вылазкой, — следующий шаг (10b);
  необратимого следа от ран (шрама, срезающего потолок здоровья) нет намеренно, он тянет за собой
  врождённые параметры (§12.19).
- Пока отряд в поле, коты не устают и вообще ничего не делают: вылазка — авторасчёт, а не
  вторая симуляция (§12.22). Плата снимается разом на возвращении.
- Потребностей две — усталость и голод. У голода **один** порог и никакой смерти: он забирает
  бодрость вдвое быстрее, и только (§12.36). Ни жажды, ни настроения, ни разных блюд: паёк один
  и закрывает шкалу целиком. Здоровье к ним не относится: это не потребность, а последствие
  вылазки (§12.37), и лечение не требует расходников — аптечка отложена до момента, когда
  производство станет надёжным контуром.
- Навыков пять («Стройка», «Вылазка», «Наука», «Ремесло», «Медицина»), и до общего потолка
  теперь дорастает не каждый: врождённый параметр режет предел у трёх доменов из пяти (§12.42).
  Параметров тоже три, по одному на ограниченный домен: сила и остальная четвёрка OXCE ждут
  боя, которого в POC нет. Растить параметры нечем — ни тренажёра, ни импланта, ни события
  таймлайна, которое их двигает; это отложено намеренно (§12.19).
- Таймлайн — два события и один вид расплаты (бодрость): фракции, «Дела» и кольцо-чекпоинт
  требуют того, чего в POC нет (§12.28). Событий, меняющих карту или отнимающих котов, нет
  намеренно — §12.10 держит линию «состояния обратимы».
- Intel — одна шкала вместо четырёх веток §4.3: «минимальные уровни Intel» это уровень «Науки»
  у кота, который сядет за тему. Четыре ветки сегодня двигались бы одним действием (§12.26).
  Тем две, и тема одна за раз; технологии открывают только тайлы (§12.27).
- Склад типо-агностичен и без приоритетов: «ящик у лаборатории», который коты пополняют, —
  отложенная идея, см. конец §12.16.
